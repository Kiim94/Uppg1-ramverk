# Laboration 1: CSS-ramverk

Denna uppgift har gått ut på att testa och utvärdera minst två valfria ramverk. För att utföra detta skulle man:
- Skapa en webbplats med minst 3 sidor
- Använda ramverken på en sida vardera
- Publicera webbplatsen via en plattform som inte är FTP/SFTP
- Ramverks-sidorna ska innehålla, förutom för- och nackdelar, en tabell och formulär
   - Ingen större funktionalitet krävdes för dessa

## Ramverk
De ramverk som använts i denna uppgift är Bootstrap samt Milligram. Bootstrap valdes på grund av att det är ett av de mest populära ramverken, 
medan Milligram valdes dels för att den (för mig) varit okänd tills denna uppgift, men även på grund av dess minimalistiska stil.
