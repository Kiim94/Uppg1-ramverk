Publicering på Netlify

Jag har valt att publicera denna webbplats till Netlify. Framförallt för att jag har använt den tidigare och därmed känner till den lite bättre än andra. Men även för att öva mer med den då jag hittills har mest använt GitHub Pages.

Språk

Netlify stödjer väldigt många olika språk, som HTML, CSS, JavaScript, TypeScript, PHP och många andra.

Det gör den perfekt för den som använder många av dessa programmeringsspråk, men också för den som inte vill göra en flerspråkig webbplats.

Kostnad

Medan Netlify är till stor del gratis att använda så finns det även möjlighet att betala för att få tillgång till fler funktioner.

Storlek

Det finns en gräns för hur stora filer får vara för att kunna laddas upp till Netlify. Maximal filstorlek är 256 MB, men för mindre webbplatser är det inte så vanligt att gå över den gränsen.

Fördelar

  • Det är enkelt att använda: om du redan vet hur du skapar ett repo i GitHub kan du koppla det till Netlify: varje gång du pushar en förändring så kommer det automatiskt att uppdatera webbplatsen som du har i Netlify.
  • Du får snabb återkoppling när något inte fungerar vid start av webbplats eller liknande.
  • Du kan även förhandsgranska innan förändringar blir live.

Nackdelar

  • Som tidigare nämnt, det är inte gratis om du vill A: ha stora filer eller B: använda mer avancerade funktioner.
  • Om trafiken till webbplatsen plötsligt skjuter i höjden kan resurser för denna månad ta slut. Har du betalversionen kan du även få oväntade höga avgifter.
  • Ta med saker som kod-stöd (vilka programmerings-språk som går att använda),
  • kostnad,
  • för- och nackdelar
  • och andra saker du tycker är utmärkande.
  • Beskriv även hur arbetssättet är för att publicera arbetsfiler till denna webbhost.
