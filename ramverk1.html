Ramverk 1: Bootstrap

Denna sida har använt Bootstrap som ramverk. Här är dess webbplats.

Fördelar

  • Det gick snabbt att komma igång och testa sig fram.
  • Webbplatsens dokumentation hade många exempel och förklarade på ett enkelt sätt vad olika stilar på komponenter med mera gjorde.
  • Många komponenter är redan färdiga att använda och går att anpassa efter behov och önskemål.

Nackdelar

  • Kanske lite uppenbart: men om Bootstrap är så pass populärt som det är så kanske det är svårt att göra en helt "unik" webbplats med det.
  • Det kan krävas lite tid och tålamod samt att ha dokumentationen till hands om man vill ändra något.
  • Märkte att det kan bli ganska långa klassnamn beroende på hur man vill anpassa komponenterna.
