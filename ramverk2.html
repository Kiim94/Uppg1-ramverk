Ramverk 2: Milligram

Denna sida har använt Milligram som ramverk. Dokumentation finns på : Milligram Documentation

Viss extra SCSS har använts för att göra sidan mer användbar/tilltalande.

Fördelar

  • Väldigt enkelt att använda: bara börja skriva HTML efter att Milligram har blivit inkluderat i projektet.
  • Om man inte vill behöver man inte använda någon specifik CSS då färdig css finns när man börjar programmera.
  • Då ramverket är flexbox-baserad är det enkelt att skapa responsiva layouter.
  • Även grid är enkelt att implementera och använda. Dessa för- och nackdelar är uppdelade med hjälp av en container, en row samt två kolumner.

Nackdelar

  • Det finns inga mer avancerade funktioner än de som redan finns. Så inga karuseller, dragspel eller navigeringsmenyer finns färdiga att implementera.
  • Det verkar uppdateras långsamt (senaste uppdateringen var 2020)
  • Vill man styla får man använda css för att manuellt göra detta (t.ex. ändra färg, animationer, rundade hörn)
